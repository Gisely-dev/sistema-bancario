# Sistema Bancário em Java

Projeto desenvolvido em Java utilizando Programação Orientada a Objetos (POO).

## Funcionalidades

- Criar contas bancárias
- Depositar valores
- Sacar valores
- Consultar saldo
- Listar todas as contas cadastradas
- Cadastro de múltiplas contas utilizando ArrayList
- Validação para impedir contas duplicadas

## Tecnologias

- Java
- Programação Orientada a Objetos (POO)
- ArrayList
- Scanner
- Estruturas de decisão (switch)
- Estruturas de repetição (do-while)

## Como executar

1. Clone o repositório.

```
git clone https://github.com/seu-usuario/Sistema-Bancario-Java.git
```

1. Abra o projeto em sua IDE Java.

2. Compile e execute o arquivo Principal.java.
